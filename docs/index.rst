Mondarth (CORE)
===============

This is a library module. It provides no Foundry VTT service direct to the user.

This module is required by all Mondarth modules. It provides a global interface ``Mondarth`` object that provides:

#. A consistent API to any external modules using Mondarth modules in Foundry VTT.
#. A facade for various Foundry VTT API elements to decouple Mondarth code.
#. Core Mondarth code.
